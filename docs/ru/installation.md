# Установка и запуск

[English](../en/installation.md) · [Deutsch](../de/installation.md) · **Русский** · [← README](../../README.ru.md)

PDF Datei Umbenenner работает на обычных офисных ПК с Windows 10 и 11. Для установки не нужны права администратора: программа живёт в собственной папке со своим окружением Python (`.venv`). Отдельной системной программой устанавливается только Tesseract OCR.

## Требования

| Компонент | Подробности |
| --- | --- |
| Windows | 10 или 11. Автоматическая установка Python предлагается на 64-битной Windows для процессоров Intel/AMD. |
| Интернет | Только во время установки (Python, пакеты Python, Tesseract). |
| Python | 3.10–3.15 с Tcl/Tk. Если его нет, `setup.bat` после вопроса устанавливает Python 3.14. |
| Tesseract OCR | Версия 5 с немецкими языковыми данными `deu` (`eng` входит в стандартную установку, `osd` рекомендуется). |
| Справочник учеников | Ваш `Schuler.csv` в папке программы (см. [руководство](user-guide.md#справочник-учеников)). |

Без Tesseract программа запускается, справочник и очередь проверки работают, но обработка, в том числе пробный прогон, заблокирована.

## 1. Выбор места

1. **Разблокируйте ZIP до распаковки:** правый щелчок по скачанному файлу → *Свойства* → отметить *Разблокировать* (*Zulassen*) → *OK*. Иначе Windows помечает каждый распакованный файл как «из интернета» и показывает предупреждение безопасности для каждого BAT-файла. `setup.bat` снимает эту пометку с файлов программы сам, но самый первый запуск `setup.bat` всё равно спросит подтверждение.
2. **Рекомендуемая папка:** локальная папка пользователя, например `C:\Users\<Имя>\PDF-Datei-Umbenenner` (`%USERPROFILE%\PDF-Datei-Umbenenner`).
3. **Без сетевых путей.** Папку вида `\\server\share\…` `cmd.exe` не может сделать рабочим каталогом; все лаунчеры сразу завершаются с кодом `51` и советуют скопировать программу на компьютер.
4. **Без папок OneDrive** (в том числе рабочего стола, перенаправленного в OneDrive). Синхронизация тысяч файлов `.venv` приводит к блокировкам файлов и сбоям установки пакетов. `setup.bat` распознаёт расположение внутри `%OneDrive%`, `%OneDriveCommercial%` или `%OneDriveConsumer%`, объясняет проблему и спрашивает, продолжать ли; ответ *нет* завершает setup с кодом `52` до какой-либо установки.
5. Положите свой `Schuler.csv` в папку программы. Без него проверка в конце setup завершится кодом `24`. Чтобы сначала попробовать программу, можно начать с копии [`demo/Schuler.csv`](../../demo/Schuler.csv).

## 2. Установка Tesseract OCR

[Документация Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html) для Windows ссылается на установщик UB Mannheim:

1. Откройте [страницу UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki) и скачайте актуальный 64-битный `tesseract-ocr-w64-setup-….exe`.
2. Запустите установщик и оставьте предложенный каталог.
3. В выборе компонентов в разделе *Additional language data* отметьте **German**. Английский и `osd` входят в стандартный набор.
4. Если Tesseract уже установлен без немецкого: запустите установщик повторно и добавьте *German* либо скопируйте `deu.traineddata` из [tessdata](https://github.com/tesseract-ocr/tessdata) в папку `tessdata` рядом с `tesseract.exe`.

Программа ищет `tesseract.exe` в `TESSERACT_CMD`, в `PATH`, в `%ProgramFiles%\Tesseract-OCR`, `%ProgramFiles(x86)%\Tesseract-OCR`, `%LOCALAPPDATA%\Programs\Tesseract-OCR` (установка только для текущего пользователя) и `%LOCALAPPDATA%\Tesseract-OCR`. Для другого каталога задайте переменную окружения `TESSERACT_CMD` с полным путём к `tesseract.exe`. Без `osd` хуже распознаются повёрнутые набок сканы; проверка выдаёт только предупреждение.

`setup.bat` не запускает установщик Tesseract сам: официальная документация описывает только ручную установку, а подпись этого установщика нельзя проверить так, как пакеты Python и Microsoft.

## 3. Запуск setup.bat

Дважды щёлкните `setup.bat`. Интерактивный setup:

1. **ищет Python** в таком порядке: `py -3.14`, `%LOCALAPPDATA%\Programs\Python\Python314\python.exe`, `py -3`, `python` из `PATH`. Кандидат принимается, только если действительно запускается и сообщает версию 3.10–3.15 — заглушка Microsoft Store `WindowsApps\python.exe` (код 9009) игнорируется. Если найден только более новый Python, setup сообщает об этом и предлагает закреплённую версию;
2. **при необходимости устанавливает Python** (только после явного *j*): см. [автоматическая установка Python](#автоматическая-установка-python);
3. **создаёт собственное окружение** `.venv` (права администратора не нужны);
4. **устанавливает пакеты** из `requirements.txt` (`pdfplumber`, `PyMuPDF`, `Pillow`) только из готовых колёс (`--only-binary=:all:`) — сборка из исходников на офисных ПК без компилятора всё равно не удалась бы. Затем проверяет пакеты, импорт приложения, `subjects_config.json` и `Schuler.csv`. Повреждённые пакеты один раз переустанавливаются без кэша. Только после успешной проверки записывается штамп `.venv\.requirements.sha256`;
5. **проверяет Tesseract** с `deu` и `eng`. Если чего-то нет, показывает пошаговую инструкцию на немецком, после согласия открывает страницу загрузки, ждёт *Enter* и проверяет снова. Если Tesseract так и не готов, setup завершается кодом `31`, `32` или `33` и сообщением `SETUP UNVOLLSTAENDIG: VERARBEITUNG NICHT VERFUEGBAR`;
6. **предлагает удобства:** ярлыки на рабочем столе и в меню «Пуск» и запуск программы;
7. **в конце ждёт нажатия клавиши**, если запущен двойным щелчком или ярлыком, чтобы итог и ошибки можно было прочитать. Из открытой консоли он не ждёт.

Если PyMuPDF не загружается из-за отсутствия среды выполнения Microsoft Visual C++ (код `34`), пакеты сначала один раз переустанавливаются. Если это не помогло, интерактивный setup отдельно спрашивает, установить ли Microsoft VC++ Redistributable; его цифровая подпись проверяется, а консоль должна быть запущена от имени администратора (повышение прав не запрашивается). Отказ или ошибка — код `34`.

### Автоматическая установка Python

Если подходящий Python не найден, setup предлагает установить его. После согласия `install_python.ps1`:

- скачивает с python.org закреплённый установщик **Python 3.14.8 (64-bit)**: `https://www.python.org/ftp/python/3.14.8/python-3.14.8-amd64.exe`;
- перед запуском проверяет подпись Authenticode: статус *Valid* и издатель `CN=Python Software Foundation`. Иначе файл удаляется и не запускается;
- тихо устанавливает Python только для текущего пользователя в `%LOCALAPPDATA%\Programs\Python\Python314` с Tcl/Tk: `/quiet InstallAllUsers=0 PrependPath=0 Include_launcher=0 AssociateFiles=0 Shortcuts=0 Include_tcltk=1 Include_pip=1 Include_doc=0 Include_test=0`. Права администратора не нужны, `PATH` не меняется. Журнал установщика — `.launcher-logs\python-installer.log`;
- затем setup находит интерпретатор по этому пути и продолжает.

Лаунчер `py` намеренно не устанавливается: его вариант «только для пользователя» добавляет свою папку в начало пользовательского `PATH` и перекрывал бы команду `py` нового [Python install manager](https://docs.python.org/3/using/windows.html#python-install-manager). Классический установщик выпускается для Python 3.14 и 3.15; начиная с 3.16 python.org оставляет только install manager. Неявная загрузка интерпретатора через install manager во всех лаунчерах отключена (`PYTHON_MANAGER_AUTOMATIC_INSTALL=false`).

Отказ, ошибка загрузки, неверная подпись или сбой установки возвращают к инструкции для ручной установки, предложению открыть [страницу Python для Windows](https://www.python.org/downloads/windows/) и коду `10`. На 32-битной Windows и ARM64 setup сообщает, что автоматическая установка там недоступна. `--unattended` и `--core-only` Python не устанавливают.

Нужные колёса существуют для Python 3.10, 3.14 и 3.15 на `win_amd64`, а для 3.14 — ещё на `win32` и `win_arm64` (проверено `pip download --only-binary=:all:`).

### Режимы без вопросов

```cmd
setup.bat --unattended
setup.bat --core-only
setup.bat --no-pause
```

- `--unattended` — без вопросов, без системных установок (Python, Tesseract, VC++ Runtime) и без ожидания клавиши. В `.venv` устанавливаются только пакеты Python. Код `0` — только если готовы пакеты, Tesseract и `deu`; иначе конкретный ненулевой код.
- `--core-only` — только пакеты Python; Tesseract не проверяется, итог напоминает, что обработке он нужен. Код `0` при готовых пакетах.
- `--no-pause` — для автоматизации: не ждать клавишу в конце (сочетается с другими параметрами).

## 4. Ежедневный запуск

Используйте ярлык **PDF Datei Umbenenner** или `start_app.bat`. Лаунчер:

- использует только собственное `.venv`, сверяет штамп `requirements.txt` и проверяет пакеты и данные;
- ремонтирует окружение только при проблемах пакетов Python: после изменения `requirements.txt` — одна обычная установка и новый штамп, при повреждённом пакете (`20`, `22`, `35`) — одна принудительная переустановка с повторной проверкой. Ошибки `subjects_config.json`, `Schuler.csv` и tkinter/Tcl никогда не запускают `pip`; отсутствие VC++ Runtime (`34`) отсылает к `setup.bat`;
- никогда не запускает `pip` из-за отсутствия Tesseract: выводит предупреждение, программа открывается, а вкладка *Verarbeitung* сообщает, что обработка заблокирована. После установки Tesseract перезапуск не нужен;
- запускает программу отдельным процессом через `.venv\Scripts\pythonw.exe` и сразу закрывается — консоль видна только во время проверок и ремонта, и её закрытие больше не завершает программу. Вывод и ошибки запуска программы пишутся в `.launcher-logs\gui.log`; если программа не может стартовать, дополнительно показывается окно сообщения;
- при ошибке ждёт нажатия клавиши, если запущен двойным щелчком или ярлыком (`--no-pause` отключает).

Второй запуск при уже открытом окне (например, повторный двойной щелчок по ярлыку) не открывает второй экземпляр, работающий с теми же файлами: появляется сообщение *PDF Datei Umbenenner ist bereits geöffnet*, а после *OK* открытое окно разворачивается и выводится на передний план. Блокировка — именованный мьютекс Windows на папку программы; после сбоя ничего не нужно удалять вручную, а копии программы в других папках друг другу не мешают.

Окно открывается размером 1200×760 по центру экрана. Если оно не помещается — например, на 1366×768 или 1920×1080 при масштабе 150 % (около 1280×720 логических точек), — окно разворачивается на весь экран, декоративный заголовок над вкладками скрывается, а список учеников на вкладке *Prüfung* уменьшается так, что все поля и кнопки остаются видимыми. Поддержку высокого DPI программа не объявляет: при масштабе 125/150 % Windows масштабирует окно целиком (текст чуть мягче, раскладка та же).

Проверка лаунчера без открытия программы (код `0`, если программа может стартовать; отсутствие OCR — только предупреждение):

```cmd
start_app.bat --health-only
```

`quick_start.bat` ничего не устанавливает и не ремонтирует. Он проверяет только наличие `.venv` (иначе код `2`) и импорт обязательных пакетов (`bootstrap.py check-packages`, около 0,3 с; иначе понятная ошибка и код `20`, `34` или `35`), затем запускает программу так же. Если окружение повреждено, используйте `start_app.bat`.

`create_desktop_shortcut.bat` (setup предлагает его запустить) создаёт ярлык **PDF Datei Umbenenner** на рабочем столе — с учётом перенаправления рабочего стола в OneDrive — и в меню «Пуск» пользователя. Ярлык указывает на `start_app.bat`, сохраняет папку программы рабочим каталогом и использует иконку программы. Если PowerShell или Windows Script Host запрещены политикой либо папка недоступна для записи, выводится понятное сообщение с ручным способом (*Отправить → Рабочий стол*).

## 5. Обновление установки

1. Закройте программу.
2. Замените файлы программы (`*.py`, `*.bat`, `*.ps1`, `requirements*.txt`, `app_icon.*`, `README*.md`, `docs\`). Не перезаписывайте свои данные: `Schuler.csv`, `Lehrer.csv`, `student_aliases.json`, `subjects_aliases.json` и файлы `manual_review.json` рядом со сканами. Если вы меняли список предметов в `subjects_config.json`, сохраните свой файл и добавьте новые записи вручную или кнопкой *Neues Fach übernehmen* на вкладке проверки.
3. Запустите программу как обычно. Изменённый `requirements.txt` обнаруживается по штампу, пакеты устанавливаются один раз. Лаунчеры и setup никогда не изменяют CSV, JSON, очередь проверки и сканы.
4. Если Tesseract с `deu` ещё не установлен, установите его и проверьте `setup.bat` или `.venv\Scripts\python.exe bootstrap.py check-ocr`.

## Коды возврата

| Код | Значение |
| --- | --- |
| `0` | Готово / успешно |
| `2` | `quick_start.bat`: нет `.venv` |
| `10` | Не найден поддерживаемый Python (и не установлен) |
| `20` | Отсутствует или повреждён обязательный пакет (`pdfplumber`, `PyMuPDF`, `Pillow`) |
| `21` | Недоступен tkinter/Tcl |
| `22` | Ошибка импорта приложения |
| `23` | Не читается `subjects_config.json` — файл не изменяется, пакеты не переустанавливаются |
| `24` | Нет или не читается `Schuler.csv` — файл не изменяется, пакеты не переустанавливаются |
| `31` | Не найден Tesseract |
| `32` | Нет языковых данных `deu` или `eng` |
| `33` | Ошибка проверки OCR |
| `34` | PyMuPDF не загружается: среда выполнения Windows/DLL (Microsoft VC++) |
| `35` | Другая ошибка импорта PyMuPDF |
| `40` | Изменился `requirements.txt` или нет штампа (внутренний) |
| `50` | Ошибка bootstrap, окружения или диагностики, в том числе неудачный запуск процесса программы |
| `51` | Программа лежит на сетевом пути (UNC) |
| `52` | Setup прерван из-за расположения в OneDrive |
| `64` | Неверный параметр лаунчера |

Setup возвращает `31`–`33`, когда пакеты готовы, а OCR нет; `start_app.bat` и `quick_start.bat` в этой ситуации запускают программу. Коды `pip` передаются без изменений. Код выхода самой программы лаунчеры больше не передают, потому что она работает отдельным процессом. Внутренние коды `install_python.ps1` (`70` загрузка, `71` подпись, `72` установщик, `73` после установки нет `python.exe`) пишутся только в журнал setup; сам setup возвращает `10`. Код `30` (прежний «не установлен необязательный PyMuPDF») выведен из обращения и не будет использован повторно.

## Решение проблем

| Признак | Что делать |
| --- | --- |
| Windows предупреждает о каждом BAT-файле | ZIP не был разблокирован. Запустите `setup.bat` один раз (он снимает пометку) или разблокируйте ZIP и распакуйте заново. |
| Setup сообщает, что нет Python | Ответьте *j*, чтобы установить Python 3.14 автоматически, или установите Python с python.org с компонентом *tcl/tk and IDLE* и повторите setup. |
| *OCR nicht verfügbar – Verarbeitung gesperrt* | Установите Tesseract с немецкими данными (раздел 2) и проверьте `setup.bat`. |
| Код `34` (Visual C++) | Запустите `setup.bat` без параметров в консоли, открытой от имени администратора, и согласитесь на установку VC++ Runtime. |
| Программа не запускается | Посмотрите `.launcher-logs\gui.log`; при проблемах лаунчера — `.launcher-logs\start_app.log` или `setup.log`. |
| Окружение повреждено | Закройте программу и запустите `start_app.bat`. Неработающее `.venv` сохраняется как `.bootstrap\venv-backup-<id>`, создаётся новое. Для полного сброса удалите только `.venv` и повторите `setup.bat` — Tesseract останется установленным. |
| Повреждён `manual_review.json` | Программа не перезаписывает его. Закройте программу, скопируйте файл и папку `manual_check` в надёжное место, сопоставьте каждый PDF с записью очереди, затем исправьте JSON или замените его на `{"review_items": []}`. |

Все диагностические журналы — файлы UTF-8 в `.launcher-logs\`: `setup.log`, `start_app.log`, `gui.log` и `python-installer.log`.
