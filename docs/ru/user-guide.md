## Обработка папки

![Вкладка Verarbeitung после пакета](../images/processing.png)

1. Выберите папку со сканами PDF (*Eingabeordner*, кнопка *Durchsuchen…*).
2. Выберите *Monat* и *Jahr*. Окно открывается с текущим месяцем; период входит в каждое имя файла.
3. При необходимости отметьте *Testmodus (keine Änderungen)* для пробного прогона.
4. Нажмите **Verarbeitung starten**.

Настройки фиксируются в начале пакета. Во время обработки папка, период и любые изменения справочника заблокированы. *Stoppen* завершает текущий PDF и останавливается между файлами; закрытие окна во время пакета предлагает такую же безопасную остановку.

Журнал перечисляет каждый документ:

- ✅ переименован — `Scan_…pdf → Nachname_Vorname_Fach_Monat_Jahr.pdf`, в той же папке;
- ⚠️ замечание, которое не блокирует, например *Geburtsdatum … in das Schülerverzeichnis übernommen* (выучена дата рождения) или автоматическое исправление имени после OCR;
- 📋 отправлен на проверку — PDF перемещается в подпапку `manual_check`, а причина и готовое предложение сохраняются в `manual_review.json` в папке сканов.

**Testmodus** рассчитывает полный план с теми же именами, но не перемещает PDF, не меняет ни `Schuler.csv`, ни алиасы и не сохраняет очередь проверки.

Для обработки нужен Tesseract OCR. Без него журнал и строка состояния показывают *OCR nicht verfügbar – Verarbeitung gesperrt*; остальные вкладки работают. См. [установку](installation.md#2-установка-tesseract-ocr).

## Имена файлов

Формат всегда один:

```text
Nachname_Vorname_Fach_Monat_Jahr.pdf
```

```text
Beispiel_Lena_Mathematik_September_2026.pdf
```

- Фамилия и имя берутся из справочника, а не из текста OCR, поэтому ошибки чтения никогда не попадают в имя файла.
- Предмет — каноническое название из списка предметов (`Mathe` → `Mathematik`).
- Месяц пишется по-немецки. Месяц и год берутся **только** из выбора в программе (или параметров CLI) — никогда из дат на формуляре, системного времени или исходного имени файла.
- Существующий файл никогда не перезаписывается. Используется первый свободный суффикс: `…_2026.pdf`, `…_2026_1.pdf`, `…_2026_2.pdf`. Имена, уже зарезервированные в том же пакете, считаются занятыми, поэтому пробный и реальный прогоны планируют одинаковые имена.

## Поддерживаемые формуляры

| Формуляр посещаемости (*Anwesenheitsnachweis*) | Старый формуляр |
| --- | --- |
| <img src="../images/form-attendance.png" width="340" alt="Вымышленный формуляр посещаемости"> | <img src="../images/form-legacy.png" width="340" alt="Вымышленный старый формуляр"> |

**Формуляр посещаемости**, с колонкой *GR/EZ* и без неё:

- имя ученика — строка над подписью *Name des Schülers*;
- дата рождения — значение над *Geburtsdatum* (необязательно, служит дополнительным ключом опознания);
- предмет читается из колонки *Fach* таблицы посещаемости. Обычно он напечатан в каждой строке; решает согласованное большинство. Записи колонки *GR/EZ* (групповое или индивидуальное занятие, часто от руки как `EZ`, `E2`, `&z`) никогда не принимаются за предмет.

**Старый формуляр:** строка заголовка *Nachname Vorname Fach* над полями *Bewilligungszeitraum*, *Monat*, *Unterrichtsart* и *Lehrer(in)*.

Вид формуляра определяется по подписям на странице, а не по имени файла. Один формуляр относится к одному предмету. Преподаватель, место, *GR/EZ*, номер BG и подписи никогда не используются для опознания ученика и построения имени файла; `Lehrer.csv` в переименовании не участвует. Имя и предмет обычно напечатаны; рукописные имена редки и идут на проверку.

## Проверка (Prüfung)

![Проверка нового ученика](../images/review-new-student.png)

Документ попадает на проверку, если программа не уверена, например:

- ученика нет в справочнике (*vermutlich ein neuer Schüler*);
- похожи несколько учеников или два чтения указывают на разных учеников;
- дата рождения на формуляре противоречит справочнику;
- предмет неизвестен, противоречив или не читается;
- OCR для этого документа не удался.

**Слева:** список документов на проверку, а под ним фрагменты исходного скана — имя, дата рождения и первые строки колонки *Fach* (для старых записей очереди без координат полей — уменьшенная страница). *PDF öffnen* открывает файл в программе просмотра PDF.

**Справа:** строка состояния называет, что нужно решить (*Schüler: …*, *Fach: …*), ниже — распознанное имя, фамилия, имя, предмет и дата рождения (`TT.MM.JJJJ`, можно изменить), поиск ученика и действия.

**Поиск ученика** работает по мере ввода: части фамилии, имени или номер в любом порядке, без учёта регистра. Без запроса сначала идут предложенные кандидаты (★, по сходству); если буквальных совпадений нет, ≈ отмечает похожие имена. Явный лидер выбран заранее. *Enter* и стрелки только выбирают ученика; *Escape* очищает поиск; изменение запроса или документа сбрасывает выбор.

| Действие | Результат |
| --- | --- |
| **Ausgewählten Schüler übernehmen** | Переименовывает PDF для выбранного ученика. С отметкой *Erkannten Namen als Alias speichern* распознанное написание запоминается, и следующий скан с тем же написанием опознаётся автоматически. |
| **Als neuen Schüler anlegen** | Добавляет нового ученика с подставленными фамилией, именем и датой рождения (при необходимости исправьте) и переименовывает PDF. |
| **Neues Fach übernehmen: …** | Появляется, если неизвестный предмет согласованно напечатан. После подтверждения предмет добавляется в `subjects_config.json` и сразу действует. |
| **Nur umbenennen** | Переименовывает PDF без изменения справочника (после отдельного подтверждения). |
| **Aus Liste entfernen** | Удаляет запись из очереди; PDF остаётся в `manual_check`. |

![Проверка: новый предмет у известного ученика](../images/review-new-subject.png)

Переименованный файл перемещается обратно в папку сканов. Используется период, сохранённый в записи очереди. Дата рождения из формуляра сохраняется для выбранного или нового ученика, если в справочнике её ещё нет — существующая дата никогда не перезаписывается. Справочник и алиасы сохраняются до перемещения PDF; если шаг не удался, запись остаётся в очереди и её можно применить повторно без повторного добавления ученика. Список противоречащих значений (например, *Deutsch, Englisch*) никогда не сохраняется как алиас.

## Справочник учеников

![Справочник учеников](../images/students.png)

Вкладка **Schüler** позволяет искать и фильтровать, добавлять и редактировать учеников, активировать и деактивировать их (история сохраняется), просматривать и удалять ошибочные алиасы, искать возможные дубликаты и импортировать обновлённый CSV.

`Schuler.csv` лежит в папке программы. Минимальный формат:

```csv
Nummer;Nachname;Vorname
1;Beispiel;Lena
```

- UTF-8 с BOM или без; кроме `Vorname` принимается исторический заголовок `Forname` (если есть оба, они должны совпадать).
- Необязательные колонки: `Aktiv` (логические значения) и `Geburtsdatum` (`TT.MM.JJJJ`; пустая ячейка — неизвестно). Дополнительные колонки, их порядок и BOM сохраняются.
- **Импорт** принимает разделители `;`, `,`, табуляцию и `|` и сначала показывает сравнение: новые, неизменённые, конфликтующие, повторяющиеся и отсутствующие записи. После подтверждения добавляются только новые бесконфликтные строки; конфликты никогда не перезаписываются, а отсутствующие исторические записи не удаляются. Сначала создаётся резервная копия `Schuler.csv.bak` (или следующий свободный суффикс), затем файл заменяется атомарно. Поиск дублей и импорт выполняются в фоне; в это время другие изменения справочника и обработка заблокированы.
- Если CSV или файл алиасов изменён вне программы, перед редактированием нажмите *Aktualisieren*.

**Дата рождения.** Необязательная колонка `Geburtsdatum` — дополнительный ключ опознания: совпадение усиливает решение, а уверенно прочитанная другая дата запрещает автоматическое решение даже при точном имени (одна путаница похожих цифр вроде 5/6 противоречием не считается). Дата заполняется автоматически только для ученика без даты — по документу с точным именем и чистым чтением даты или по решению оператора в *Prüfung*. Колонка добавляется при первой необходимости с резервной копией. Справочник с датами рождения — персональные данные и остаётся только локальным.

**Алиасы** — подтверждённые альтернативные написания; они хранятся рядом с CSV в `student_aliases.json`:

```json
{"version": 1, "aliases": [{"name": "Beispie1 Lena", "student_number": 1}]}
```

Алиас создаётся только решением оператора; автоматические исправления их никогда не создают.

## Предметы

`subjects_config.json` содержит список предметов и стандартные сокращения:

```json
{
  "subjects": ["Biologie", "Chemie", "Deutsch", "Englisch", "Geografie", "Informatik",
               "Mathematik", "Physik", "Sachkunde", "Sachunterricht"],
  "aliases": {"Mathe": "Mathematik", "Bio": "Biologie", "Geo": "Geografie", "Sachunt.": "Sachunterricht"}
}
```

*Sachkunde* и *Sachunterricht* — разные предметы. Неверно прочитанные названия сопоставляются со списком, если достаточно близок ровно один предмет. Новый предмет добавляется правкой файла или кнопкой *Neues Fach übernehmen* на вкладке проверки. Подтверждённые исправления написания предметов хранятся в `subjects_aliases.json`.

## Файлы данных

| Файл | Где | Содержимое | В Git |
| --- | --- | --- | --- |
| `Schuler.csv` | папка программы | справочник учеников (персональные данные) | нет |
| `student_aliases.json` | папка программы | подтверждённые написания имён учеников | нет |
| `Lehrer.csv` | папка программы | список преподавателей; в переименовании не используется | нет |
| `subjects_config.json` | папка программы | список предметов и сокращения | да (по умолчанию) |
| `subjects_aliases.json` | папка программы | подтверждённые написания предметов | да (пустой) |
| `manual_review.json` | каждая папка сканов | очередь проверки с предложениями и доказательствами | нет |
| `manual_check\` | каждая папка сканов | PDF, ожидающие проверки | нет |
| `.launcher-logs\` | папка программы | диагностические журналы | нет |
| `.venv\`, `.bootstrap\` | папка программы | собственное окружение Python и его резервные копии | нет |

CSV и JSON всегда записываются через временный файл и атомарную замену. Повреждённая очередь или файл алиасов никогда не заменяются молча пустыми: программа сообщает ошибку и оставляет файл без изменений.
